# Docs

Project documentation, organized by topic.

- `architecture/` — Technical architecture deep-dives, data model commentary, sequence diagrams
- `product/` — Product specs, user flows, personas, positioning
- `curator/` — Curator personality system, prompts, voice guides, eval criteria
- `api/` — API contracts (auto-generated OpenAPI placeholder)
- `runbooks/` — Operational playbooks (deploy, rollback, incident response)
- `decisions/` — Architectural Decision Records (ADRs); index at `/DECISIONS.md`
- `onboarding/` — Setup guide for new contributors

Top-level project docs (README, PROJECT, ARCHITECTURE, DECISIONS) live at the repo root for agent and contributor visibility.
