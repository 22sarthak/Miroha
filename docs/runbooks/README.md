# Runbooks

Operational playbooks. When something is on fire, look here.

Planned files:

- `deploy.md` — Standard deploy procedure (Phase 11)
- `rollback.md` — How to roll back a bad deploy
- `llm-quota-exhausted.md` — What to do when Gemini free tier runs out
- `database-incident.md` — Neon connection issues
- `cold-start-debugging.md` — Onboarding flow problems
- `curator-quality-regression.md` — When users report bad Curator behavior

Each runbook follows the format: Symptom → Diagnosis steps → Resolution → Prevention.
