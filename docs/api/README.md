# API documentation

API contracts between the frontend and backend.

Planned content:

- `openapi.json` — auto-generated from FastAPI on every deploy (Phase 1+)
- `endpoint-conventions.md` — Naming, versioning, error format
- `auth.md` — Clerk JWT validation, session handling

For the OpenAPI spec at runtime, see `http://localhost:8000/docs` once the backend is running.
